# Bug Hunting — RS School

## О проекте

Bug Hunting — учебный проект курса **RS School Fullstack Engineering**, направленный на развитие навыков отладки, анализа существующего кода и исправления ошибок в веб-приложениях.

Проект состоит из пяти независимых страниц, реализованных с использованием HTML, CSS и JavaScript.

В исходной версии проекта содержалось 45 намеренно внесённых ошибок, связанных с оформлением интерфейса, обработкой событий, управлением состоянием и отображением данных.

В ходе выполнения задания выявлены и исправлены все 45 заявленных ошибок.

## Реализованная функциональность

### 1. Прайс-таблица

Страница содержит три тарифных плана: Basic, Pro и Enterprise.

Выполнены исправления расположения карточек, оформления списков преимуществ, цветовой схемы, внутренних отступов, скруглений и выравнивания элементов.

Тариф Pro визуально выделен среди остальных.

**Исправлено ошибок: 8 из 8.**

### 2. Портфолио-галерея

Страница представляет собой галерею карточек проектов.

Реализованы:

- Расположение карточек по три в строке.
- Перенос карточек при недостаточной ширине контейнера.
- Центрирование галереи.
- Сохранение пропорций изображений.
- Плавные эффекты при наведении.
- Горизонтальное расположение тегов проектов.

**Исправлено ошибок: 7 из 7.**

### 3. Список задач (To-Do)

Интерактивное приложение для управления списком задач.

Реализованы:

- Добавление новых задач.
- Проверка пользовательского ввода.
- Отметка задач как выполненных.
- Отмена статуса выполнения.
- Удаление отдельных задач.
- Фильтрация по статусам «Все», «Активные», «Выполненные».
- Подсчёт количества невыполненных задач.
- Очистка выполненных задач.
- Корректное обновление списка без дублирования элементов.

**Исправлено ошибок: 10 из 10.**

### 4. Корзина товаров

Приложение для добавления товаров в корзину и управления заказом.

Реализованы:

- Добавление товаров в корзину.
- Объединение одинаковых товаров в одну позицию.
- Увеличение и уменьшение количества товаров.
- Удаление отдельных позиций.
- Вычисление стоимости каждой позиции.
- Подсчёт общей стоимости корзины.
- Отображение суммарного количества товаров.
- Применение промокода `SALE10` со скидкой 10%.
- Полная очистка корзины.
- Отображение сообщения при отсутствии товаров.

**Исправлено ошибок: 10 из 10.**

### 5. Каталог товаров

Приложение с поиском, фильтрацией и сортировкой товаров.

Реализованы:

- Первоначальное отображение всех товаров.
- Поиск по части названия без учёта регистра.
- Фильтрация товаров по категориям.
- Сортировка по возрастанию и убыванию цены.
- Восстановление исходного порядка товаров.
- Совместное применение поиска, категории и сортировки.
- Отображение количества найденных товаров.
- Полный сброс параметров фильтрации.
- Обновление DOM без дублирования карточек.

**Исправлено ошибок: 10 из 10.**

## Локальный запуск

Для запуска проекта не требуется установка зависимостей или выполнение сборки.

1. Клонировать репозиторий:

   ```bash
   git clone https://github.com/Kondrati3vMaksim/Rss-bug-hunting.git
   ```

2. Перейти в директорию проекта:

   ```bash
   cd Rss-bug-hunting
   ```

3. Открыть `index.html` в браузере либо запустить проект с помощью расширения Live Server в Visual Studio Code.

4. На главной странице выбрать необходимое приложение.

## Подход к отладке

При работе над проектом применялся последовательный подход к поиску и исправлению ошибок:

1. Воспроизведение некорректного поведения.
2. Определение ожидаемого результата.
3. Исследование проблемного участка с помощью Chrome DevTools.
4. Анализ значений переменных, состояния приложения и DOM.
5. Поиск причины ошибки.
6. Внесение исправления.
7. Повторная проверка функциональности.

При отладке JavaScript использовались breakpoints, Scope, Watch и Call Stack. При исправлении CSS применялись инструменты Elements, Styles и Computed.
